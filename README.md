# HSR 워프 대시보드

붕괴: 스타레일의 **전언(워프) 기록**을 내 PC로 가져와 **천장·운·픽뚫(50/50)·월별 통계**를 보여주는 작은 프로그램입니다. `hsr-warp.exe` 하나만 실행하면 브라우저에 대시보드가 자동으로 열립니다.

- **설치 불필요** — 실행파일 하나가 전부입니다.
- **완전 로컬** — 모든 처리는 내 PC에서만 일어나고, 기록이 외부로 전송되지 않습니다. 계정 로그인도 필요 없습니다.
- **안전하게 누적** — 다시 조회해도 과거 기록은 보존되고 새 기록만 더해집니다.

---

## 빠른 시작

### 1. 게임에서 전언 기록을 엽니다 ⚠️ (가장 중요)

게임을 **실행만 하는 것으로는 안 됩니다.** 게임 안에서 직접 **[전언] → [기록]** 화면을 열어 **뽑기 목록이 화면에 보이게** 해야 합니다. 이때 게임이 인증 정보(authkey)를 PC 캐시에 기록하고, 이 프로그램은 그걸 읽어 조회합니다.

> 이 인증 정보는 시간이 지나면 만료됩니다. **조회 직전에** 전언 기록 화면을 한 번 열어두세요.

### 2. `hsr-warp.exe` 를 실행합니다

검은 콘솔 창이 뜨고, 기본 브라우저에 대시보드가 자동으로 열립니다(예: `http://127.0.0.1:8787/dashboard.html`).

> 다운로드한 프로그램이라 **처음 실행 시 Windows가 경고**할 수 있습니다(서명되지 않은 프로그램). 직접 받은 파일이 맞다면 **추가 정보 → 실행**을 누르면 됩니다.

### 3. 조회합니다

- **게임 경로**는 자동으로 채워집니다(이전 사용 경로 → 없으면 자동 탐지). 비어 있거나 틀리면 게임 폴더(`…\Star Rail Games`)를 직접 입력하세요.
- **조회** 버튼을 누르면 새 기록만 실시간으로 가져오고 차트가 갱신됩니다.
- 기존에 저장된 기록은 조회 없이도 바로 표시됩니다.

### 4. 종료

콘솔 창을 닫거나 콘솔에서 `Ctrl+C` 를 누릅니다.

## 저장되는 파일

`hsr-warp.exe` 와 **같은 폴더**에 자동으로 만들어집니다.

| 폴더/파일 | 내용 |
|---|---|
| `data\` | 워프 기록(월별 `warp_YYYYMM.json`). 표준 SRGF v1.0 형식이라 다른 도구로도 가져갈 수 있습니다. |
| `config.json` | 마지막에 쓴 게임 경로 |
| `logs\` | 실행 기록(날짜별 `hsr-warp-YYYY-MM-DD.log`). 문제가 생겼을 때 원인 확인에 씁니다. |

다른 PC로 옮기거나 백업하려면 `data\` 폴더를 통째로 복사하면 됩니다.

## 문제 해결

| 메시지 / 증상 | 해결 |
|---|---|
| **authkey 만료** | 게임을 켜는 것만으로는 갱신되지 않습니다. 게임 안에서 **[전언] → [기록]** 화면을 다시 직접 연 뒤(목록이 보이게) 조회하세요. 메시지에 표시된 *발급 시각*이 오래됐다면 화면을 안 연 것입니다. |
| **조회가 너무 잦습니다 (서버 호출 제한)** | 짧은 간격으로 여러 번 조회하면 서버가 잠시 막습니다. **1~2분 기다렸다가** 다시 조회하세요. |
| **게임 경로를 못 찾음 / webCaches 없음** | 경로 입력란에 게임 설치 폴더(`…\Star Rail Games`)를 직접 입력하세요. |
| 그 밖의 오류 | `logs\` 폴더의 최신 로그 파일을 열어보면 어느 단계에서 멈췄는지 알 수 있습니다. 더 자세한 기록이 필요하면 `HSRWARP_LOG=debug` 를 설정하고 실행하세요(에러엔 스택트레이스가 함께 남습니다). |

## 대시보드에서 보는 지표

- **운 지표** — 5★ 평균 천장을 이론 평균 **62.5회**(종합 확률 1.6%)와 비교. 낮을수록 행운입니다.
- **평균 천장** — 캐릭터 5★ 평균 천장(+ 최고/최악 운).
- **픽승률(50/50)** — 한정 배너에서 50/50 승부 중 픽업을 뽑은 비율(확정 획득은 별도 집계).
- **월별 집계** — 월별 뽑기 수·성옥·획득 5★.

### 판정 기준
- **50/50**: 5★ 획득 **시점의 배너 픽업(rate-up)** 대상이면 **픽승**, 아니면 **픽뚫**으로 봅니다. 시점 기반이라 상시풀 편입·리런·콜라보·Celestial Invitation을 정확히 처리합니다(픽업 일정 데이터는 `web/schedule.json`).
- 픽업 일정에 없는 시점(주로 갓 나온 신규 패치)의 5★는 **미확인**으로 표시됩니다 — 일정을 갱신하면 해소됩니다.
- 공식 확률/천장: 캐릭터 0.6%(종합 1.6%)/하드천장 90, 광추 0.8%/하드천장 80.

## 자주 묻는 것

- **계정이 위험하지 않나요?** 이 프로그램은 게임이 PC에 남긴 조회용 인증 정보를 읽어 **읽기 전용** 비공식 기록 API만 호출합니다. 비밀번호나 계정 정보는 다루지 않고, 게임에 어떤 변경도 하지 않습니다.
- **데이터가 어디로 전송되나요?** 어디로도 보내지 않습니다. 호요버스 조회 서버와 내 PC 사이의 통신만 있고, 결과는 내 PC에만 저장됩니다.
- **여러 계정을 쓸 수 있나요?** 현재는 마지막으로 조회한 계정 기준으로 저장됩니다.

<summary>개발자용 (소스 빌드)</summary>

`node` 만 있으면 됩니다 — `go` 는 빌드 스크립트(`scripts/run-go.mjs`)가 자동으로 찾습니다.

```powershell
npm run build    # 정적 단일 exe 빌드(-s -w)
npm start        # 빌드 후 실행
npm test         # go test ./...  +  node web/analyze.test.js
npm run vet      # go vet ./...
```

도구를 직접 쓸 경우:

```powershell
go build -ldflags="-s -w" -o hsr-warp.exe .
go test ./...
node web/analyze.test.js
```

- 분석 로직은 `web/analyze.js`, 배너 픽업 일정 데이터는 `web/schedule.json` 단일 소스이며, 단위 테스트는 `web/analyze.test.js`(`node web/analyze.test.js`)가 같은 디렉터리에서 검증합니다.
- 아이콘 변경: `go run ./tools/genicon` → `goversioninfo -64 -o resource_windows_amd64.syso` 로 재생성.
- 신규 패치 출시 시 `web/schedule.json`의 `schedule` 배열에 새 페이즈 `{s,e,c,l}`를 추가하고 최상위 `version`을 +1 하세요(c=캐릭터·l=광추 픽업 item_id; 픽업=Mantan21/HSR-Warp-Simulator, item_id=StarRailRes). `main`에 push 하면 사용자 앱이 시작 시 자동으로 받아 반영합니다(릴리스 불필요). 누락 시 그 시점 5★가 '미확인'으로 표시됩니다.
